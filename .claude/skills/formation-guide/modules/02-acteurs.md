# Module 02 — Les acteurs
Fiche : §2 · Profils : tous (dev / techlead : optionnel) · Durée : ~5 min

## Concept
Il y a trois familles : **Anthropic** (Claude), **OpenAI** (GPT, Codex) et l'**open source** (Llama,
Mistral, Qwen…, à héberger soi-même). Les classements changent chaque mois : compare sur 3 critères qui
ne changent pas — **capacité agentique** (tient-il une tâche longue ?), **coût**, **contrôle des données**.

## Pas 1/1 — Les 3 critères
**Cas concret** : ton client interdit que son code sorte de son réseau. Quel critère décide ?

**Exercice** : réponds-moi en 2 lignes : pour **ton** contexte (client, données sensibles ou non,
budget), lequel des 3 critères pèse le plus, et pourquoi ?

**Vérification** : tu cites les 3 critères et tu en choisis un avec une raison.

## À retenir
Propriétaire = capacité agentique clé en main. Open source = contrôle et coût, au prix de l'intégration.

## Question de contrôle
Q : cite les 3 critères pour comparer des LLM.
Attendu : capacité agentique, coût, contrôle / données.
